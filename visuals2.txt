TECHNICAL NOTES FOR WHEN CODING BEGINS:
  Player frame size 48x64 chosen because:
    - JOUEUR_W=28 and JOUEUR_H=48 are collision box dimensions
    - Sprite will be drawn slightly larger than the hitbox (common in 2D games)
    - Hitbox stays 28x48, sprite drawn centered on it at 48x64

  Enemy collision boxes will be:
    - Guard:    36x60 (sprite 48x64)
    - Worker:   30x52 (sprite 40x56)
    - Enforcer: 52x72 (sprite 64x80)

  If the generator can't do transparent backgrounds:
    Use flat magenta (#FF00FF) background.
    Code will use SDL_SetColorKey to make it transparent.
