  assets/logo.png      <- the game logo shown in the hero (PNG, transparent
                          background recommended; ~512px works well)

placeholder instead of a broken image. As soon as you add the file with this
exact name/path, it appears automatically — no code changes needed.

(Optional) You can also add an og-image here for social sharing and point the
<meta property="og:image"> tag in index.html at it.
